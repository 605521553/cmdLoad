## 阶段三：剪贴板驱动快速收藏（已完成）

### 数据层

- SQLite migration 2：命令 `source_type`、`content_hash`、`ai_annotation_status`。
- 独立 `clipboard_entries` 表；内容指纹、去重、来源、敏感标记、可选命令关联。
- 迁移前备份；旧命令来源回填 `manual`；内容指纹回填。
- 设置 schema 3：监听开关、历史上限、保留天数、复制后隐藏。
- JSON schema 2：保留命令来源/AI 状态；继续接受 schema 1。

### Windows 剪贴板

- Win32 当前 `CF_UNICODETEXT` 读取，失败重试、保留原文、非文本返回空。
- 官方 WinRT 系统历史读取：检查开关、获取条目、提取文本、状态映射、只读。
- `AddClipboardFormatListener` 消息窗口 + `WM_CLIPBOARDUPDATE` 工作线程。
- 连续更新合并、去重、敏感过滤、数量/期限清理、自身复制抑制。
- 一键清空本地历史；不修改系统历史/永久命令。

### 保存与 UI

- 一键保存当前/系统历史/本地历史文本；自动标题、Shell 猜测、unknown、未分类。
- 严格原文去重、来源字段、Saved/Favorite 分离、跳转命令详情。
- 快捷面板三视图、当前置顶、系统顺序、本地倒序、跨来源去重。
- `Ctrl+S`、`Enter`、`↑/↓`、`Esc`、搜索、预览展开、保存状态、复制反馈。
- 敏感内容二次确认；取消不持久化。
- 手动添加只要求命令原文；标题空自动生成；Shell 可选 unknown。
- 设置剪贴板面板和真实管理器剪贴板摘要页。
- 复制后自动隐藏设置；保存不关闭面板。

### 实测验收

- 系统历史真实返回可读条目并逐条保存。
- 关闭 Windows 剪贴板历史后，当前剪贴板保存仍成功。
- 本地监听在窗口隐藏时记录外部复制；关闭监听后停止新增；自身复制不进入本地历史。
- 多行/空白/CRLF 原文保存一致；重复保存返回已有命令。
- 敏感内容未确认不写入；确认后才写入。
- 清空本地历史不删除命令；删除命令不清理系统历史。
- 重启后命令、来源、本地历史均保留。
- 复制后自动隐藏快捷面板实际生效。
